# EcoFly — Односторінковий вебсайт циркулярної біоекономіки (Київ)

Статичний односторінковий сайт (Single Page Application без сторонніх залежностей) для проєкту переробки рослинних органічних відходів за допомогою личинок чорної левової мухи (*Hermetia illucens*, BSF) у кормовий протеїн, жир і зоогумус (фрас).

---

## 1. Структура файлів

```
ecofly/
├── index.html                  # Головна сторінка (семантичний HTML5, WCAG AA, SEO, JSON-LD)
├── 404.html                    # Автономна сторінка помилки 404
├── README.md                   # Ця інструкція
├── css/
│   └── style.css               # Дизайн-система, CSS-змінні (:root), світла й темна теми, @media print

└── assets/
    ├── favicon.svg             # Векторна іконка сайту
    ├── og-image.png            # Open Graph зображення для прев'ю в соцмережах (1200×630 px)
    └── ecofly-passport-sample.html # Статичний зразок офіційного бланка паспорта партії для друку та перегляду
```

## 2. Перелік маркерів для перевірки та заповнення

Перед фінальним запуском або передачею інвесторам знайдіть та оновіть наступні фрагменти:

### Маркери `[ЗАПОВНИТИ]`:
1. **Лабораторні показники продуктів** (`index.html` та `js/data.js`):
   * Профіль сирого протеїну BSF: `buyers.prod1_val` (наприклад, *«Сирий протеїн: 42–45%, вологість: 6–8% за даними ДП "Укрметртестстандарт"»*).
   * Показники ліпідів (жиру): `buyers.prod2_val` (наприклад, *«Сирий жир: 28–32%, лауринова кислота: ~40%»*).
   * Показники зоогумусу: `buyers.prod3_val` (наприклад, *«Органічна речовина >70%, NPK 3.5-1.2-1.8»*).
2. **Дати та локація пілоту** (`index.html` та `js/data.js`):
   * `timeline.t3_desc`: вказати конкретні заплановані дати монтажу першого пілотного модуля у Києві (наприклад, *«Осінь 2026, промисловий майданчик у Подільському районі»*).
3. **Біографія засновника** (`index.html` та `js/data.js`):
   * `team.lead_bio`: додати 2–3 речення про освіту, професійний досвід або мотивацію Владислава Колісника.
4. **Контактні дані** (`index.html` та `js/data.js`):
   * Нікнейм Telegram: замінити `@ecofly_kyiv` на реальний контакт засновника або бота.
   * Робочий Email: замінити `contact@ecofly.kyiv.ua` на дійсну адресу.
   * Посилання на LinkedIn компанії або профілю засновника.
5. **Ендпоінти форм:**
   * У формах `id="waste-form"` та `id="buyers-form"` у полі `action="#"` замініть `#` на посилання вашого сервісу (див. розділ 4).

### Маркери `[ПЕРЕВІРИТИ]`:
1. **Юридичний статус кормового білка з комах в Україні** (`table.row3_bsf`, `faq-5`, `risks.r1_desc`):
   * У ЄС личинки BSF дозволені в аквакультурі (Регламент 2017/893) та птахівництві/свинарстві (Регламент 2021/1372).
   * В Україні: уточнити стан гармонізації кормового законодавства з Держпродспоживслужбою та актуальний статус реєстрації технічних умов (ТУ) для білка з Hermetia illucens.

## 3. Як змінювати контент та числа

* **Числа та коефіцієнти розрахунків:** редагуйте файл `js/data.js` у секції `ECOFLY_DATA.CALCULATION`. Калькулятор автоматично підтягує значення з цього файлу. Біля кожної константи наведено першоджерело (*Eawag/Sandec*).
* **Цінові орієнтири:** редагуйте `ECOFLY_DATA.PRICING` у `js/data.js`.
* **Українські тексти:** редагуйте безпосередньо `index.html`. Сайт за замовчуванням оптимізований для індексації пошуковими системами та відображається навіть якщо у клієнта вимкнено JavaScript.
* **Англійські тексти:** редагуйте словник `ECOFLY_DATA.EN_TRANSLATIONS` у `js/data.js`.

## 4. Підключення відправки заявок без власного бекенду

Форми на сайті повністю адаптовані для статичного хостингу та містять:
* Вбудований захист від ботів (приховане поле `hp_company_url`);
* Таймер затримки не менше 8 секунд між відкриттям сторінки та відправкою;
* Клієнтську валідацію обов'язкової згоди на обробку контактних даних;
* Кнопку **«Скопіювати заявку»**: якщо форма не підключена до бекенду, користувач натискає цю кнопку, дані копіюються в буфер обміну у вигляді структурованого тексту, і користувач може надіслати їх у Telegram чи на Email.

### Варіант А: Formspree (найпростіший)
1. Зареєструйтесь безкоштовно на [formspree.io](https://formspree.io/).
2. Створіть нову форму та отримайте URL вигляду `https://formspree.io/f/xyzabwqr`.
3. У файлі `index.html` замініть `action="#"` на ваш URL у формі:
   ```html
   <form id="waste-form" action="https://formspree.io/f/xyzabwqr" method="POST">
   ```

### Варіант Б: Google Forms
1. Створіть Google Форму з відповідними полями.
2. Скопіюйте посилання на форму або інтегруйте Google Apps Script вебхук, який записуватиме дані напряму в Google Таблицю.

## 5. Безкоштовна публікація сайту в інтернеті

### Спосіб 1: GitHub Pages (Рекомендовано)
1. Створіть новий безкоштовний репозиторій на [GitHub](https://github.com/), наприклад `ecofly-website`.
2. Завантажте всі файли з папки `ecofly/` у корінь репозиторію:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for EcoFly landing"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/ecofly-website.git
   git push -u origin main
   ```
3. Перейдіть у **Settings** репозиторію → **Pages** (ліва колонка).
4. У пункті **Build and deployment / Branch** виберіть `main` і теку `/ (root)`, натисніть **Save**.
5. За 1–2 хвилини ваш сайт стане доступний за безкоштовною адресою: `https://ВАШ_ЛОГІН.github.io/ecofly-website/`.

### Спосіб 2: Netlify (за 30 секунд без Git)
1. Перейдіть на [app.netlify.com](https://app.netlify.com/) і увійдіть.
2. Перетягніть папку `ecofly` мишкою у вікно браузера в зону **«Drag and drop your site folder here»**.
3. Netlify миттєво згенерує робочу адресу вигляду `https://ecofly-kyiv.netlify.app/` із безкоштовним SSL-сертифікатом.

## 6. Тестування та перевірка доступності

* **Контрастність (WCAG AA):**
  * Світла тема: фони `#FFFFFF` / `#F7F9F6`, текст `#142419` (15.4:1), акцентний бурштин `#9A5B00` (5.4:1), приглушений `#566E5F` (5.5:1).
  * Темна тема: фони `#0D1611` / `#14231A`, текст `#EEF5F0` (14.8:1), акцентний бурштин `#F4A236`, кнопки з зеленим фоном `#5ECA95` мають темний текст `#0D1611` (9.1:1).
* **Адаптивність:**
  * `375px`: мобільний телефон, без горизонтального скролу, доступне меню-бургер з керуванням з клавіатури та закриттям по `Esc`.
  * `768px`: планшети, 2-колонкова адаптивна сітка.
  * `1440px`: великі ноутбуки та монітори, максимальна ширина контейнера 1200px.
* **Друк (@media print):**
  * Натискання `Ctrl+P` або кнопки друку приховує меню, кнопки та фони, формуючи світле охайне односторінкове резюме проєкту для інвесторів.
