# EcoFly: сайт

Одна сторінка про переробку органічних відходів личинками чорної левової мухи (Київ). Українська і англійська мови, темна й світла тема. Працює без сервера, на безкоштовному GitHub Pages.

## Що лежить у папці

| Файл / папка | Для чого |
|---|---|
| `index.html` | сама сторінка (тексти) |
| `css/style.css` | вигляд (кольори, шрифти) |
| `js/main.js` | поведінка (калькулятор, форми, мови) |
| `js/config.js` | **єдиний файл, який вам треба редагувати**: форми, контакти, підписи до фото |
| `assets/photos/` | сюди кладіть фото (імена файлів у `ПРОЧИТАЙ.txt`) |
| `assets/favicon.svg`, `assets/og-image.png` | іконка вкладки й картинка для Telegram/Facebook |
| `404.html` | сторінка «не знайдено» |

## Як оновити сайт на GitHub (без програмування)

1. Відкрийте репозиторій `ecofly-website` на github.com.
2. Натисніть **Add file → Upload files**.
3. Перетягніть **вміст** папки `ecofly` (файли `index.html`, `404.html`, `README.md` і папки `css`, `js`, `assets`), а не саму папку `ecofly`.
4. Внизу натисніть **Commit changes**. Через 1–2 хвилини сайт оновиться. Якщо бачите стару версію, натисніть Ctrl+F5.

Старі файли з такими самими іменами будуть замінені. Файли, яких більше немає в новій версії (наприклад, старі `.svg`-малюнки), можна видалити вручну: відкрийте файл, натисніть кошик, **Commit changes**.

## Як додати фото

1. Підберіть фото (власні або з Wikimedia Commons / Unsplash / Pexels). **Репозиторій публічний, тому для фото без дозволу є ризик скарги від автора.**
2. Назвіть файли так, як у `assets/photos/ПРОЧИТАЙ.txt` (наприклад, `hero-larvae.jpg`). Стисніть до ~500 КБ, наприклад на squoosh.app.
3. Завантажте їх у `assets/photos/` через **Add file → Upload files** (відкрийте цю папку на GitHub).
4. У `js/config.js` у розділі `photos` впишіть автора й ліцензію для кожного фото. Підписи зʼявляться внизу сайту автоматично.

Фото, якого немає, замінюється гарним кольоровим фоном. Нічого не ламається.

## Як зробити так, щоб заявки приходили вам

Поки нічого не налаштовано, кнопка «Надіслати» лише копіює текст заявки.

**Варіант А (рекомендую): Formspree.**
1. Зареєструйтесь на formspree.io (безкоштовно, до 50 заявок на місяць).
2. Створіть форму, скопіюйте адресу виду `https://formspree.io/f/xxxxxxxx`.
3. У `js/config.js` вставте її між лапками в `endpoint` потрібної форми (`waste`, `buyers`, `partner`; можна одну адресу на всі три).
4. Заявки приходитимуть на пошту й лежатимуть у кабінеті Formspree. Це і є ваш «кабінет заявок».

**Варіант Б: Google Форма.** Створіть форму, скопіюйте посилання в `googleForm`. Сайт скопіює текст заявки й відкриє форму, відвідувач вставить його.

## Контакти й дані

У `js/config.js` заповніть `contacts` (пошта, Telegram, LinkedIn), коротке біо засновника й `sources.organics` (посилання на джерело цифри «понад 40%»). Порожні поля на сайті просто не показуються.

## Як змінити текст

Відкрийте `index.html` на GitHub (олівець угорі праворуч). Український текст написано прямо в розмітці, англійський лежить в атрибутах `data-en="..."`. Змінюйте текст між тегами, не чіпайте самі теги.

## Чесні обмеження

- Усі цифри на сайті орієнтовні й взяті з літератури (Eawag/Sandec, Регламент ЄС 2017/893). Паспорт партії на сайті ілюстративний, дані вигадані й так підписані.
- Особистого кабінету з базою заявок немає. Для цього є Formspree або Google Таблиця.
